# Middletown HVAC — Public Website Assets

Web-optimized photos and videos for **mtownhvac.com**, served publicly via GitHub Pages
so they can be embedded in Web.com page-builder HTML with plain `<img>` tags.

- Source of truth (full-resolution originals + site code) lives in the **private**
  `middletown-hvac-website` repo. Never add documents, pricing, or internal files here —
  everything in this repo is public.
- Images are resized to max 1600px and compressed for fast page loads.
- Folder layout mirrors the private repo: `images/{outdoor-units,air-handlers,furnaces,boilers,indoor-air-quality,general}/` and `videos/`.

Embed URL pattern:

    https://mtownhvac-gif.github.io/mtownhvac-assets/images/<category>/<name>.jpg
